



• cd ~/Desktop/project-name
 

• npm init -y
  Creates package.json if it is missing.

• npm install
  Installs packages already listed in package.json.

• npm install express better-sqlite3 express-session express-session-better-sqlite3

  Installs all packages manually if needed.

• node server.mjs
  Starts the server.

• node --watch server.mjs
  Starts the server and restarts it automatically after changes.

• http://localhost:3000
  Open this address in your browser.

• Control + C
  Stops the server.

• node --version
  Checks whether Node is installed.

• npm --version
  Checks whether npm is installed.
